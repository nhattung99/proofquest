# Neon visual assets

Presentation-only artwork for the owner-supplied orange neon reference. Created with the built-in ImageGen tool, not the CLI/API fallback. These are decorative illustrations, not proof receipts or verification results. All titles, links, buttons and verification states remain real HTML/UI elements.

## Saved project assets

- `public/art/verify-bind.webp`: glass X and wallet tiles connected by a neon link.
- `public/art/quiz.webp`: books, graduation cap and question tiles.
- `public/art/shield.webp`: glass shield above an orange holographic platform.
- `public/art/wallet-mark.svg`: code-native decorative wallet mark.
- `public/art/ambient-wave.svg`: code-native background wave.

Generated PNG originals were preserved in the tool's generated-images directory. Project copies were resized and encoded as WebP with their alpha channel retained for page loading performance.

## Final prompt set

### Verify and bind illustration

Create a production website decorative asset only, NOT a full website or screenshot. A polished premium 3D illustration for ProofQuest's Verify & Bind X card. Two floating dark violet glass square tiles, one with a large clean white X symbol, the other an orange faceted fox wallet emblem, joined by a short glowing golden chain link. Hovering above a thin elliptical holographic orange platform. Three-quarter perspective, crisp beveled glass, warm orange rim lighting, subtle purple reflections, rich cinematic rendering. Isolated on genuinely transparent alpha background, include the complete platform and all glow without clipping. Wide composition, generous transparent margins. No UI, no buttons, no text except the white X symbol. Intended displayed at right side of black/orange feature card, about 350x220 CSS pixels. Match a luxurious futuristic orange neon Web3 interface.

### Quiz illustration

Generate a single premium 3D decorative website illustration, isolated on a truly transparent alpha background. A stack of three glossy violet and dark charcoal books topped with a black graduation cap with golden orange tassel; the top book cover has only the word 'Primus' clearly legible. Two small floating purple glass question-mark tiles flank the books. All hovering above a thin orange neon elliptical holographic platform. Three-quarter camera perspective, luxurious beveled edges, vivid orange rim light and restrained purple highlights. Entire objects and soft glow visible with transparent margins, landscape composition for a 350x220 CSS pixel illustration on the right of a dark Quiz card. No UI, no buttons, no surrounding scene, no other text. A polished futuristic orange neon Web3 educational asset.

### Header shield

Create a single premium 3D shield illustration for a dark orange neon Web3 website header. A translucent beveled glass security shield with a thick illuminated orange-gold checkmark, slight violet glass edge reflections, hovering over thin elliptical rings of an orange holographic podium. Crisp sophisticated 3D product render, subtle bloom, warm orange rim light. Full shield and platform visible, centered, wide composition with transparent margins, genuinely transparent alpha background. No text, no UI, no website mockup, no extra objects.
